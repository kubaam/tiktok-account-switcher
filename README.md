# TikTok Account Switcher

Chrome extension (Manifest V3) for switching between your own TikTok accounts by swapping tiktok.com session cookies.

- Save the logged-in account (nickname is detected automatically).
- Switch accounts with one click; open TikTok tabs reload.
- Add another account: clears TikTok cookies and opens the login page.

All data stays in `chrome.storage.local`. See [PRIVACY.md](PRIVACY.md).

## Install from source
`chrome://extensions` → Developer mode → Load unpacked → select this folder.
